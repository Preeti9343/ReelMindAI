# ReelMind AI

### From Raw Footage to Creative Stories

ReelMind AI is an AI-powered video creation platform that transforms raw videos and multiple clips into engaging short-form reels.

## Main Features
- AI-powered video understanding
- Automatic scene detection
- Smart clip selection
- Automatic reel generation
- AI-generated captions and hooks
- Video preview and export
- User-controlled video storage and retention

## Technology Stack
- Frontend: Next.js, React, TypeScript
- Backend: Python, FastAPI
- Database: PostgreSQL
- Video Processing: FFmpeg, OpenCV
- AI: Vision models and language models

## Project Structure
- frontend: User interface
- backend: APIs and application logic
- ai-engine: Video understanding and AI processing
- docs: Project documentation
